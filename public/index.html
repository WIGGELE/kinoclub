Что и как синхронизируется

YouTubeПолностью: play, пауза, перемотка
VK ВидеоПолностью (официальный JS API VK). Время VK отдаёт целыми секундами, поэтому точность около секунды. Закрытые видео и видео с запретом встраивания не откроются
VimeoПолностью (официальный Player SDK)
RuTubeПолностью (postMessage API плеера)
.mp4 / .webm / .m3u8Полностью. Сайт-источник должен разрешать загрузку из браузера (CORS), для .m3u8 это обязательно
ФайлПолностью: у каждого свой экземпляр того же файла, передаётся только время
Если RuTube или VK не ответят на команды управления, сайт честно переключится на ручную синхронизацию («Старт вместе»).

Профиль

PNG, JPEG, WebP или GIF до 5 МБ. Картинка сожмётся до квадрата 96×96 прямо в браузере, на сервер уйдёт только маленькая копия (до 32 КБ), которая живёт, пока вы в комнате.
