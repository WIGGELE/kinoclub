Сюда кладутся ваши аудиозаписи для эмодзи.

1. Скопируйте файл сюда, например  laugh.mp3  (поддерживаются mp3, ogg, wav, m4a).
   Лучше короткие звуки (до 3–4 секунд) и небольшие файлы (до ~300 КБ): они загружаются у всех заранее.
2. Откройте manifest.json. В разделе "sounds" есть заготовки: если имя файла совпадает, ничего менять не нужно.
   Новый звук добавляется строкой:  "id": { "file": "имя.mp3", "title": "Название", "volume": 1 }
3. В разделе "bindings" привяжите эмодзи к id:  "😂": "laugh"
   Одному звуку можно привязать несколько эмодзи, а эмодзи без привязки просто летят без звука.
4. Закоммитьте и задеплойте (на Render: git push). Локально достаточно сохранить файлы.

Пока файла нет на диске, звук не используется, а эмодзи всё равно работают.
