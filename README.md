# Киноклуб

Сайт для совместного просмотра видео. Один человек создаёт комнату, остальные заходят по ссылке или коду. Play, пауза и перемотка синхронизируются у всех. Есть чат, летающие комментарии поверх видео (как на Bilibili), реакции со звуками эмодзи и аватарки.

## Запуск локально

Нужен Node.js 18 или новее.

```bash
npm install
npm start          # http://localhost:3000
npm test           # протокольные тесты сервера
```

Чтобы проверить в одиночку, откройте сайт в двух вкладках и зайдите в одну комнату.

## Развёртывание на Render (бесплатный тариф)

1. Загрузите проект в репозиторий GitHub (папку `node_modules` загружать не нужно, она в `.gitignore`).
2. На render.com: **New → Web Service**, выберите репозиторий. Либо **New → Blueprint**: параметры возьмутся из `render.yaml`.
3. Если настраиваете вручную: Runtime `Node`, Build `npm install`, Start `npm start`, Instance Type `Free`, Health Check Path `/healthz`.
4. Переменные окружения не обязательны. Порт Render задаёт сам (`PORT`), сервер слушает `0.0.0.0`.
5. Обновление: `git push`, Render пересоберёт сервис сам.

Что важно знать про Free:

- После ~15 минут без запросов сервис засыпает, первый заход занимает до минуты. Сайт показывает «Сервер просыпается…» и сам подключается, когда сервер поднимется. Искусственно «будить» его по таймеру мы не делаем.
- Память и диск не сохраняются между перезапусками. Комнаты, чат и аватарки живут в памяти процесса. После пробуждения первый вернувшийся участник восстанавливает в комнате видео и позицию (play придётся нажать заново), остальные подтягиваются к нему.
- Пустая комната удаляется через 10 минут (`ROOM_TTL_MS`), поэтому память не растёт.

## Что можно смотреть

| Источник | Синхронизация | Примечание |
|---|---|---|
| YouTube | полная | ссылка на видео, youtu.be, shorts, live |
| **VK Видео** | **полная** | официальный JS API VK (`VK.VideoPlayer`). Принимаются ссылки vk.com, vk.ru, vkvideo.ru вида `.../video-123_456` и код встраивания (`video_ext.php`). Время VK отдаёт целыми секундами, поэтому точность около секунды |
| **RuTube** | **полная** | postMessage API плеера. Приватные видео со ссылкой с `?p=` тоже работают |
| Vimeo | полная | официальный Player SDK |
| Прямая ссылка `.mp4` / `.webm` | полная | сервер-источник должен отдавать видео в браузер |
| `.m3u8` (HLS) | полная | подгружается hls.js; нужен CORS на стороне источника |
| Файл с компьютера | полная | у каждого свой экземпляр файла, передаётся только время |

### Как работает синхронизация RuTube и VK Видео

Видео открывается в `iframe`, а сайт управляет им через официальные API: когда кто-то нажимает паузу, play или перематывает, у остальных плеер получает ту же команду. Работает в обе стороны: любой участник может управлять просмотром.

Что нужно знать:

- Если реклама внутри плеера (у VK и RuTube она бывает), во время неё синхронизация приостанавливается.
- Браузер может не дать запустить play чужому плееру без вашего клика по странице. Тогда нажмите ▶ один раз.
- Если API не отвечает (скрипт VK заблокирован расширением или защитой от отслеживания, видео закрытое), сайт честно переключится на **ручной режим**: появится баннер с кнопкой «Старт вместе» (отсчёт 3-2-1, дальше каждый жмёт play сам). У VK документация отдельно предупреждает, что API может не работать в Firefox и Safari при включённой защите от отслеживания.
- Закрытые видео и видео, где автор запретил встраивание, не откроются ни в каком режиме.

## Звуки эмодзи: как добавить свои записи

Сервер и браузер уже готовы, не хватает только ваших файлов. Звуки в проект не добавлены намеренно.

1. Положите файл (mp3, ogg, wav или m4a) в `public/sounds/`. Лучше до 3-4 секунд и до ~300 КБ: файлы заранее загружаются у всех.
2. Откройте `public/sounds/manifest.json`. В разделе `sounds` уже есть заготовки (`laugh.mp3`, `applause.mp3`, `wow.mp3`, `fire.mp3`, `sad.mp3`, `love.mp3`): если назовёте файл так же, больше ничего менять не нужно. Новый звук добавляется строкой:
   ```json
   "boom": { "file": "boom.mp3", "title": "Бум", "volume": 1 }
   ```
3. В разделе `bindings` привяжите эмодзи к звуку: `"💥": "boom"`. Одному звуку можно привязать несколько эмодзи.
4. Локально достаточно сохранить файлы (манифест перечитывается раз в 15 секунд). На Render: `git push`.

Как это работает: при нажатии на эмодзи сервер проверяет его, смотрит привязку и рассылает всем участникам событие с **идентификатором** звука, а не сам файл. Файлы загружаются и декодируются в браузере заранее. Звук без файла на диске игнорируется, эмодзи при этом работают как обычно. В панели эмодзи у эмодзи со звуком есть точка в углу.

Защита: один участник может вызвать звук не чаще раза в 1,2 с, вся комната: не больше 8 звуков за 3 с. У каждого события есть сквозной номер, поэтому повторная доставка (например, после переподключения) не проигрывает звук второй раз. Браузеры не дают играть звук без касания страницы: пока его не было, показывается подсказка, после первого клика звук разблокируется. Громкость и полное отключение звуков: ⚙️ в настройках или 🔊 в панели.

Задержка зависит от сети и браузера у каждого участника, поэтому звук звучит у всех **почти** одновременно, но не секунда в секунду.

## Летающие комментарии и реакции

- Поле «Летящий комментарий» под видео: Enter отправляет, видео не перехватывает фокус. Цвет меняется кружком слева.
- Комментарии распределяются по дорожкам, не наезжая друг на друга. Если дорожек не хватает, ждут в очереди (старые отбрасываются). Анимация идёт через Web Animations на композиторе (`transform`), число одновременных комментариев ограничено плотностью.
- В ⚙️ настройках: скорость, размер, прозрачность, плотность, включение сообщений чата в поток, показ реакций. 💬 включает и скрывает комментарии одним нажатием. Настройки хранятся в браузере.
- Панель эмодзи (😊): 7 категорий, поиск по русским и английским словам, недавние. Реакция поднимается над видео у всех участников; одновременно на экране не больше 24.
- Всё это находится внутри блока плеера, поэтому работает и в полноэкранном режиме (кнопка ⛶ под видео).

## Аватарки

Нажмите на своё имя справа вверху (или «Выбрать аватарку» на входе): 12 готовых или своя картинка (PNG, JPEG, WebP, GIF до 5 МБ). Картинка в браузере обрезается до квадрата 96×96 и сжимается до ~28 КБ, на сервер уходит только эта копия (проверяется по содержимому, до 32 КБ). Сервер держит её в памяти, пока участник в комнате, диск не используется, платных сервисов нет. Если переподключились или сервер перезапустился, аватарка отправляется заново автоматически.

## Безопасность

Весь текст вставляется в страницу через `textContent`, сервер очищает управляющие символы и ограничивает длину и частоту сообщений. Источники проверяются на сервере (разрешённые схемы, хосты для встраивания). У страницы есть Content-Security-Policy без inline-скриптов, WebSocket принимает подключения только с того же сайта (для отладки с другого адреса: `ALLOW_ANY_ORIGIN=1`). Загруженные аватарки отдаются с `nosniff` и своим CSP.

```

lib/media.js         проверка источников, аватарок, эмодзи, манифеста звуков

public/css/app.css   стили
public/js/util.js    настройки, аватарки, мелкие утилиты
public/js/players.js адаптеры плееров (YouTube, VK Видео, RuTube, Vimeo, video/HLS)

public/js/danmaku.js летающие комментарии
public/js/emoji.js   панель эмодзи
public/js/app.js     связка: соединение, синхронизация, чат, настройки
public/emoji.json    эмодзи, категории и ключевые слова для поиска
public/sounds/       ваши звуки + manifest.json
test/                протокольные тесты (node:test)
```

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | 3000 | порт (на Render задаётся сам) |
| `HOST` | 0.0.0.0 | адрес привязки |
| `ROOM_TTL_MS` | 600000 | сколько хранить пустую комнату |
| `MAX_ROOMS`, `MAX_CONNECTIONS` | 300, 600 | предохранители памяти |
| `ALLOW_ANY_ORIGIN` | не задано | `1` отключает проверку Origin у WebSocket |

## Ограничения

- Комнаты, чат и аватарки хранятся в памяти и пропадают при перезапуске сервера.
- Если сайт открыт по https, ссылки на видео тоже должны быть https.
- Браузер может заблокировать автозапуск видео: тогда нажмите ▶ в плеере один раз.
- Максимум 20 человек в комнате.
